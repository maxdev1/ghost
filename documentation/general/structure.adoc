[cols="1,3",options="header"]
|===
|Path |Contents
|`applications/` |Userspace applications, drivers and libraries; ƒenster is a separate Git repository.
|`documentation/` |Developer and user reference documentation.
|`kernel/src/kernel/` |Kernel sources, including boot, memory, scheduling, IPC and filesystem code.
|`kernel/extra/` |Kernel linker scripts.
|`libapi/` |Public syscall headers, shared service interfaces and syscall wrappers.
|`libc/` |Ghost's C library and runtime support.
|`patches/ports/` |Recipes and patches for third-party software.
|`patches/toolchain/` |Compiler and binutils patches.
|`sysroot/` |Files installed into the live system's ramdisk.
|`target/` |Boot assets and generated ISO/install assets.
|`tools/` |Host utilities, including the ramdisk writer.
|`third_party/` |Vendored dependencies and their licenses.
|===

Kernel code must not include application headers. Interfaces shared with userspace
belong in `libapi` and must remain C compatible. PCI and ACPI service messages are
defined in `ghost/system/pci.h` and `ghost/system/acpi.h`; their userspace libraries
provide client helpers on top of those interfaces.
