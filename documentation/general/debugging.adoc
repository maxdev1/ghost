Kernel and driver logs use the first serial port. Capture them while booting
QEMU:

[source,sh]
----
qemu-system-x86_64 -cdrom target/ghost.iso -m 1024 -smp 2 \
  -serial file:/tmp/ghost.serial.log -no-reboot
----

For GDB, add `-s -S` to pause before execution and expose a server on port 1234.
Use an x86-64-capable GDB with `kernel/kernel` as the symbol file:

[source,text]
----
target remote localhost:1234
break kernelMain
continue
----

When debugging container-built artifacts, map `/ghost/source` to the local
checkout. Use distinct serial-log paths for concurrent VMs.
