= Ramdisk format
:toc: left
:last-update-label!:

include::../common/homelink.adoc[]

The live system's ramdisk is a sequence of file/directory records written by
`tools/ramdisk-writer`. Numeric fields are little-endian; records continue to EOF.

[cols="1,2,3",options="header"]
|===
|Bytes |Field |Meaning
|1 |Type |0: directory; 1: file.
|4 |Entry ID |Unique record identifier.
|4 |Parent ID |Containing directory.
|4 |Name length |Byte count of the following name.
|Name length |Name |Name bytes, without a terminator.
|===

File records append:

[cols="1,2,3",options="header"]
|===
|Bytes |Field |Meaning
|4 |Data length |Byte count of the file contents.
|Data length |Data |File contents.
|===

Root ID 0 is implicit and has no record. The writer emits each directory before
its children. `sysroot/.rdignore` controls excluded paths. Installed FAT systems use ordinary files and bootstrap modules
instead of a packed ramdisk; see <<loader#,Boot>>.
