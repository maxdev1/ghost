Ghost boots through Limine into an x86-64 ELF kernel. The kernel entry point is
`kernelMain`; Limine supplies a framebuffer, physical memory map, four-level
page tables, the RSDP and boot modules.

The required higher-half direct-map offset is `0xffff800000000000`. Kernel
initialization sets up memory, interrupts and scheduling before starting the
userspace services.

== Root filesystem

* Live ISO: Limine loads `/boot/ramdisk`, which contains the system files.
* Installed disk: `root=fat:XXXXXXXX:YYYYYYYY` identifies the MBR disk signature
  and the FAT volume's starting LBA as eight hexadecimal digits each. Limine loads
  individual bootstrap services/libraries; FAT mounts that volume as `/`.
  The older disk-only selector remains accepted. An explicit LBA allows partition
  2 or 3 to supply the root independently of other FAT mounts.

Installed boots do not require a ramdisk file. The boot configuration and
bootstrap module list are generated from the installed files.
